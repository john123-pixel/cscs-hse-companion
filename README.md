# CSCS HS&E Digital Companion

Free digital companion for buyers of *CSCS Health, Safety & Environment Test Preparation 2026–2027*.

- **Single-file app:** `dist/CSCS-HSE-Companion.html`, with every image built in. Works offline.
- **Website version:** `index.html` + `images/` + `sw.js`.
- **Rebuild after editing:** `python3 build/build_data.py && python3 build/build_app.py`
- See `OWNER_NOTE.md` for uploading and settings, and `TEST_REPORT.md` for the checks run.
